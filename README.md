# Désamorceur de Bombes

![Static Badge](https://img.shields.io/badge/En%20cours%20-%20orange?label=Status) ![GitHub top language](https://img.shields.io/github/languages/top/BOU-CIEL1/D-samorceur-de-Bombe) ![GitHub Tag](https://img.shields.io/github/v/tag/BOU-CIEL1/D-samorceur-de-Bombe?label=version)

## Description
Un jeu où le but est de choisir le bon fil afin de désamorcer la bombe.

## Fonctionnalités
- 2 modes de jeux principaux:
  - Mode classique:
    - 3 modes de difficultés entre Facile (3 fils), Normal (4 fils) et Difficile (5 fils)
    - 2 vies données au joueur, s'il perd ses 2 vies, il a perdu
  - Mode infini:
    - Le joueur commence avec 3 vies et doit choisir entre 3 fils, tous les 5 niveaux, le joueur gagne 1 vie supplémentaire mais 1 fil supplémentaire est ajouté aux choix
    - La partie s'arrête quand le joueur n'a plus de vie
